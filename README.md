# Windows IME Caret Indicator

Windows의 실제 텍스트 입력 캐럿 옆에 현재 한국어/영어 IME 입력 상태를 표시하는 경량 상주 유틸리티입니다.

## 현재 개발 상태

현재 버전은 `0.1.0-dev1` 개발 단계입니다. Windows x64 정식 릴리즈 전 실제 Windows 빌드, 프로그램별 동작 검증, 설치·자동실행·다중 모니터·DPI 검증이 남아 있습니다.

## 동작 구조

- 실제 키보드 포커스를 받은 텍스트 입력 위치만 표시 대상으로 삼습니다.
- 캐럿 위치 감지는 UI Automation 3의 TextPattern2 `GetCaretRange`를 우선 사용합니다.
- TextPattern2가 캐럿 위치를 제공하지 못하면 Win32 `GetGUIThreadInfo` 캐럿 정보를 보완 경로로 사용합니다.
- 0길이 UI Automation 캐럿 범위가 화면 사각형을 제공하지 않는 경우 인접 문자 범위를 최소한으로 확장하여 캐럿 모서리를 계산합니다.
- 한국어/영어 입력 상태는 포커스 스레드의 키보드 레이아웃과 IMM32 상태를 결합해 판정합니다.
- 표시는 검은색 배경과 흰색 `한`/`영` 문자로 구성하며, 포커스를 가져가지 않고 마우스 입력을 통과시킵니다.
- 기본 위치는 캐럿 우하단이며 화면 가장자리에서는 좌·상 방향 후보 위치로 자동 전환합니다.
- Windows 시작 시 자동 실행, 표시 일시정지/재개, 종료 기능을 트레이 메뉴에서 제공합니다.

## 개발용 실행

정식 릴리즈가 나오기 전까지는 개발 도구가 필요한 상태입니다.

- `--self-test`: IME 정규화, DPI 크기 계산, 화면 가장자리 배치 자체검증을 실행합니다.
- `--test-host`: Win32 편집 컨트롤이 있는 수동 테스트 창을 실행합니다.
- `--diagnose`: 현재 캐럿 및 IME 판정 정보를 진단 출력합니다.

## 지원 목표

- Windows 10/11 x64
- Chrome, Edge, ChatGPT 웹 작성창
- Word, Excel, Outlook
- Electron 및 WebView2 계열 앱
- 고전 Win32 텍스트 입력 컨트롤
- 서로 다른 DPI의 다중 모니터

## 알려진 제한

아직 정식 검증 전이므로 위 지원 목표를 PASS로 간주하지 않습니다. 현재 저장소에는 개발 과정에서 생성된 중간 추적 초안도 남아 있으며, 자동 Windows 빌드에서는 정식 TextPattern2 실행 경로만 선택하여 검증할 예정입니다.
