# Windows IME Caret Indicator

Windows의 실제 텍스트 입력 캐럿 옆에 현재 한국어/영어 IME 입력 상태를 표시하는 경량 Windows 상주 유틸리티입니다.

## 버전

현재 정식 릴리즈 후보 버전은 `0.1.0`입니다.

## 화면과 표시 의미

텍스트 입력이 가능한 컨트롤이 실제 키보드 포커스를 가지면, 프로그램은 마우스 포인터가 아니라 실제 입력 캐럿을 추적해 캐럿 근처에 작은 검은색 상태 상자를 표시합니다.

- `한`: 다음 키 입력이 한국어 IME의 한글 입력 상태로 처리됩니다.
- `영`: 다음 키 입력이 영문/Alphanumeric 상태로 처리됩니다.
- 표시창은 캐럿 깜빡임과 무관하게 유지되며, 포커스를 가져가거나 마우스 입력을 가로채지 않습니다.
- 화면 가장자리와 다중 모니터 작업 영역을 고려해 캐럿을 가리지 않는 후보 위치로 자동 조정합니다.

## 동작 구조

- 캐럿 위치는 UI Automation 3의 TextPattern2 `GetCaretRange`를 우선 사용합니다.
- UI Automation이 신뢰할 수 있는 캐럿 좌표를 제공하지 못하면 Win32 `GetGUIThreadInfo`의 포커스/캐럿 정보를 보완 경로로 사용합니다.
- 0길이 UI Automation 캐럿 범위가 화면 사각형을 제공하지 않으면 인접 문자 범위를 최소 확장해 캐럿 모서리를 계산합니다.
- 한국어/영어 상태는 실제 포커스 GUI 스레드의 키보드 레이아웃과 IMM32 입력 상태를 결합해 판정합니다.
- WinEvent/UI Automation 포커스·캐럿 이벤트를 중심으로 추적하고, 제한된 보정 조회만 사용합니다.
- 오버레이는 topmost/no-activate/input-transparent 창으로 동작합니다.

## 설치

1. GitHub Releases의 `WindowsImeCaretIndicator-Setup-0.1.0.exe`를 내려받습니다.
2. 설치 프로그램을 실행합니다.
3. 설치가 끝나면 시스템 트레이에서 Windows IME Caret Indicator가 실행 중인지 확인할 수 있습니다.
4. 기본 설치는 사용자별 설치이므로 Windows 로그인 때마다 UAC 승인을 반복해서 요구하지 않습니다.

## Windows 시작 시 자동 실행

설치 시 사용자별 Windows 시작 프로그램에 등록됩니다. 시스템 트레이 메뉴의 **Windows 시작 시 자동 실행 켜기/끄기**에서 이후 동작을 변경할 수 있습니다.

## 트레이 메뉴

- **표시 일시 정지**: 캐럿 옆 상태 표시를 숨깁니다.
- **표시 재개**: 상태 표시를 다시 활성화합니다.
- **Windows 시작 시 자동 실행 켜기/끄기**: 로그인 자동 실행을 변경합니다.
- **종료**: 상주 프로그램을 종료합니다.

설정은 다음 실행에도 유지됩니다.

## 제거

Windows의 설치된 앱 목록에서 **Windows IME Caret Indicator**를 제거하거나 설치 폴더의 제거 프로그램을 실행합니다. 제거 시 프로그램의 사용자별 자동 실행 등록도 정리됩니다.

## 지원 Windows

- Windows 10 x64
- Windows 11 x64

보안 데스크톱(UAC 보안 화면), 잠금/로그인 화면, Winlogon처럼 일반 애플리케이션 접근이 제한되는 별도 데스크톱은 지원 범위에서 제외합니다.

## 검증 범위

정식 후보는 Windows CI에서 다음 항목을 자동 검증합니다.

- 결정적 자체검사 19/19
- Chrome 및 Microsoft Edge의 input/textarea/contenteditable 캐럿 추적
- Microsoft Korean IME의 실제 키 입력을 사용한 한글 입력 및 한/영 전환 왕복
- Windows x64 self-contained publish
- 설치 프로그램 생성
- 무인 설치/제거 및 시작 프로그램 등록/정리

## 알려진 제한

Windows의 앱·컨트롤 구현과 보안 경계에 따라 UI Automation 또는 고전 Win32 캐럿 정보가 제한될 수 있습니다. 일반 사용자 데스크톱에서의 상주 사용을 대상으로 하며, 운영체제가 일반 앱의 접근 또는 표시를 차단하는 보안 데스크톱은 지원하지 않습니다.
